▶ আমার সাবস্ক্রিপশন

শুরু করার আগে একবার সেটআপ

YouTube তোমার সাবস্ক্রিপশন লিস্ট শুধু তোমার নিজের অনুমতিতে দেয়, তাই একটা বিনামূল্যের Google Client ID লাগবে।

  1. console.cloud.google.com এ গিয়ে একটা নতুন প্রজেক্ট বানাও।
  2. "APIs & Services → Library" থেকে YouTube Data API v3 Enable করো।
  3. "OAuth consent screen" এ গিয়ে External সিলেক্ট করে সেটআপ করো, আর Test users এ তোমার নিজের Gmail যোগ করো।
  4. "Credentials → Create credentials → OAuth client ID → Web application"।
  5. Authorized JavaScript origins এ এই সাইটের ঠিকানা দাও (যেমন )।
  6. যে Client ID পাবে সেটা নিচে বসাও।

তোমার সাবস্ক্রাইব করা চ্যানেলগুলোর ভিডিও

অন্য কোনো রেকমেন্ডেশন নেই, শুধু যাদের সাবস্ক্রাইব করেছ তাদের ভিডিও।
